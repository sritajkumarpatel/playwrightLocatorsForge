## Locators for Playwright / Playwright MCP

This repo maintains a locator map under `locators/` via
[playwright-locators-forge](https://github.com/) — one markdown file per
page/component, ranked by `locator-priority.yaml` at the repo root.

**Before using Playwright MCP to inspect a page or write a test:**

1. Check `locators/INDEX.md` for the page/route you're working on.
2. Open the matching `locators/<path>.md` file (or run
   `forge resolve --page <route-or-file> --element <name>` from the repo
   root) and use the rank-1 locator for each element you need.
3. Only fall back to a live Playwright MCP DOM snapshot when:
   - the element isn't in the locator map yet (new/unscanned UI), or
   - every candidate for that element is marked `dynamic: yes` (the
     value is a runtime binding, e.g. Angular `[attr.data-testid]`, and
     needs to be confirmed against the live page), or
   - `locators/<path>.md` has an element flagged `⚠️ stale` (source
     changed since the last scan — verify before trusting it).
4. When generating or updating Playwright tests, prefer the locator
   string exactly as given in the `locator` column (e.g.
   `getByTestId("submit-btn")`) rather than re-deriving a new one.
5. If you add new UI without a matching entry in `locators/`, note that
   the map is stale for that file — the human owner reruns `forge scan`
   to catch it up (or you may run it yourself if you have shell access:
   `forge scan` from the repo root).

Do not hand-edit files under `locators/` — they're regenerated by
`forge scan`. To change locator preferences globally, edit
`locator-priority.yaml` and run `forge rank`.
